00

This is a bridge

apeSketch captures hand ink and turns it into a durable document for agents and for the ape* toolchain. It is not a whiteboard product and not a CAD modeller. The Document is the language. Clients emit Ops. The Session is live authority on the LAN.

Capture

Tablet or Wi-Fi client. Strokes with time, pressure, stable IDs.

Document

Python source of truth. Ops in. Session Document out.

Egress

Structured ink plus on-demand raster. Then promote into apeCAD.

01

Is / is not

Is

  • Ink bridge: stylus → Session Document → agents / apeCAD
  • Document-first Python library, MIT
  • Dual egress: structured strokes + raster
  • LAN Session host, one process per instance root
  • Preferred ports 9966 / 9967, not machine identity

Is not

  • A whiteboard SaaS or Excalidraw competitor
  • apeCAD (that is spatial intent)
  • apeWorkbench (that is the Habitat shell)
  • OS-level “phone as Wacom”
  • A chat UI
02

The chain

  1. Client Android or desktop UI emits Ops. It does not own the Document.
  2. Session Live authority on the LAN. HTTP board, WebSocket, pair page. One host per --root.
  3. Document Canonical ink store in Python. Strokes, layers, timing. Dual agent bundle when asked.
03

Door

Install the library. Start a Session host in the folder you want as the instance root. 

pip install apeSketch
python -m apeSketch

Opens a board on preferred port 9966 (HTTP) with WebSocket on 9967. Pair at /pair. Point another folder with --root; a second instance binds the next free pair.

04

Brain

Product and architecture live in AProjects/ — ADRs, memory, specs. Locked: ink bridge, Python Document, LAN Session host, instance-scoped root.

Status: pre-alpha. MIT. Part of the ape* toolchain, not a second apeWorkbench.
